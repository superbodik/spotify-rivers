# spotify-rivers

Расширение Spicetify для десктопного Spotify: бесконечная очередь похожих треков («река») плюс кнопка «Моя волна» / «My Wave» в плеер-баре для мгновенного запуска, и отдельный Windows-апдейтер, который проверяет новую версию при входе в систему и ставит её без участия пользователя.

## Как это устроено

- `extension/rivers.js` — сам Spicetify-расширение. Следит за очередью (`Spicetify.Queue.nextTracks`), и когда треков остаётся мало, запрашивает похожие через внутренний (недокументированный) эндпоинт автовоспроизведения Spotify — `hm://autoplay-enabled/query` → `hm://radio-apollo/v3/stations/...` — и добавляет их через `Spicetify.addToQueue`. Защита от повторов и зацикливания на одном исполнителе — через скользящее окно недавних треков/артистов. Кнопка «Моя волна» (плеер-бар, `Spicetify.Playbar.Button`) включает/выключает этот режим и сразу докидывает треки; подпись на русском или английском — по языку клиента (`navigator.language`). Раз в несколько часов расширение сверяет `version.json` на GitHub и показывает уведомление, если вышла новая версия — само расширение себя не обновляет, это делает апдейтер.
- `updater/spicetify_updater.py` — отдельный процесс на Python. Скачивает `version.json`, сравнивает версии, при необходимости скачивает `dist/rivers.js`, проверяет SHA-256, атомарно заменяет файл в папке расширений Spicetify и запускает `spicetify apply`. Лог — `%LOCALAPPDATA%\spicetify-updater\updater.log`.
- `dist/rivers.js` — опубликованная версия расширения, именно её скачивает апдейтер. `scripts/release.py` держит её в синхроне с `extension/rivers.js`.
- `version.json` — манифест для апдейтера: версия, ссылка на `dist/rivers.js`, его SHA-256.

## Честно о рисках (см. также открытые вопросы в исходном документе)

Публичный Web API Spotify заблокировал `/recommendations` для новых приложений с 27 ноября 2024 — поэтому расширение его не использует вообще. Вместо этого оно дёргает тот же недокументированный внутренний эндпоинт, которым пользуется встроенный Autoplay самого Spotify-клиента, через `Spicetify.CosmosAsync`. У этого подхода два следствия:

- Не требует регистрации приложения, Client ID или OAuth — работает поверх уже залогиненной сессии клиента.
- Эндпоинт нигде официально не задокументирован и может измениться с очередным обновлением Spotify. Расширение логирует ошибки в консоль DevTools и показывает уведомление, если подбор треков не удался, вместо того чтобы падать молча — но путь эндпоинта может потребовать проверки/правки после обновления клиента.

## Настройка

Автоматически (делает всё из шагов ниже сразу):

```
pip install pyinstaller
python scripts/setup.py --github-repo USER/REPO
```

Ставит Spicetify, если его ещё нет, подставляет `USER/REPO` в нужные файлы, копирует расширение в `%LOCALAPPDATA%\spicetify\Extensions` и включает его, собирает `spicetify_updater.exe`, создаёт задачу в Планировщике (запуск при входе в Windows, без прав администратора). Любой шаг можно пропустить флагом `--skip-install` / `--skip-apply` / `--skip-build` / `--skip-task`. На GitHub коммит/пуш скрипт не делает — это руками.

Вручную, по тем же шагам:

1. Поставь [Spicetify](https://spicetify.app/) и Python 3.
2. Пропиши свой репозиторий вместо `USER/REPO`: в `extension/rivers.js` (`VERSION_MANIFEST_URL`), в `updater/spicetify_updater.py` (`MANIFEST_URL`), в `version.json` (`url`) — и закоммить/запушь.
3. Подключи расширение:
   ```
   spicetify config extensions rivers.js
   spicetify apply
   ```
   (сам файл `rivers.js` должен лежать в папке расширений Spicetify — `%LOCALAPPDATA%\spicetify\Extensions`).
4. Собери апдейтер в exe:
   ```
   pip install pyinstaller
   pyinstaller --onefile --noconsole updater/spicetify_updater.py
   ```
5. Добавь задачу в Планировщик заданий Windows (`taskschd.msc`): триггер «при входе в систему», действие — запуск `dist/spicetify_updater.exe` (из папки, куда PyInstaller положил exe). Апдейтер не требует прав администратора.

## Выпуск новой версии

```
python scripts/release.py 1.0.1
```

Поднимает `CURRENT_VERSION` в `extension/rivers.js`, пересобирает `dist/rivers.js`, пересчитывает SHA-256 и обновляет `version.json`. Дальше — закоммитить и запушить.

## Проверка

- Расширение загружается после `Ctrl+R` в Spotify — смотри консоль DevTools на строку `[rivers] расширение загружено`.
- Кнопка «Моя волна» видна в плеер-баре и переключается по клику.
- При коротком плейлисте в конце подгружаются новые треки без остановки воспроизведения.
- Повышение версии в `version.json` приводит к обновлению после следующего запуска апдейтера.
- Намеренно испорченный хеш в `version.json` отменяет обновление — видно в логе апдейтера.
- Апдейтер не падает без интернета — ошибка уходит в лог, процесс завершается кодом 1.
