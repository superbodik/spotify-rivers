# spotify-rivers

Для десктопного Spotify: страница «Моя волна» / «My Wave» (отдельная вкладка в левой навигации, как у Яндекс Музыки, но в стиле Spotify) плюс кнопка-дублёр в плеер-баре — запускают бесконечный поток треков и следят, чтобы он не прерывался. Отдельный Windows-апдейтер проверяет новую версию при входе в систему и ставит её без участия пользователя.

## Как это устроено

- `extension/rivers.js` — Spicetify-расширение, ядро логики. Следит за очередью (`Spicetify.Queue.nextTracks`) и при каждой смене трека выключает Repeat (`Spicetify.Player.setRepeat(0)`), чтобы встроенный Autoplay самого Spotify-клиента — надёжный, первоклассный механизм «музыка не кончится» — не блокировался повтором контекста. Поверх этого пытается сам докинуть релевантные треки через внутренний эндпоинт автовоспроизведения (`hm://autoplay-enabled` → `hm://radio-apollo`) с защитой от повторов и зацикливания на одном исполнителе — но если эндпоинт недоступен (см. ниже), тихо откатывается на встроенный Autoplay вместо того, чтобы спамить ошибками. Кнопка «Моя волна» в плеер-баре (`Spicetify.Playbar.Button`) и отдельная страница (см. ниже) — два входа в один и тот же режим. Раз в несколько часов сверяет `version.json` на GitHub и уведомляет о новой версии — само расширение себя не обновляет, это делает апдейтер.
- `custom-app/moya-volna/` — Custom App Spicetify: отдельный пункт в левой навигации Spotify со своей страницей (анимированный фон, большая кнопка play, текущий трек, статус волны). Не трогает хрупкий DOM полки «Моя медиатека» — использует официальный механизм Custom Apps. Запускает воспроизведение и включает волну через `window.ShadowRivers`, который расширение кладёт в глобальную область.
- `updater/spicetify_updater.py` — отдельный процесс на Python. Скачивает `version.json`, сравнивает версии, при необходимости скачивает `dist/rivers.js`, проверяет SHA-256, атомарно заменяет файл в папке расширений Spicetify и запускает `spicetify apply`. Лог — `%LOCALAPPDATA%\spicetify-updater\updater.log`.
- `dist/rivers.js` — опубликованная версия расширения, именно её скачивает апдейтер. `scripts/release.py` держит её в синхроне с `extension/rivers.js`.
- `version.json` — манифест для апдейтера: версия, ссылка на `dist/rivers.js`, его SHA-256.

## Честно о рисках — и что из этого уже произошло

Публичный Web API Spotify заблокировал `/recommendations` для новых приложений с 27 ноября 2024, поэтому расширение его не использует вообще. Изначально оно дёргало недокументированный внутренний эндпоинт `hm://autoplay-enabled` через `Spicetify.CosmosAsync` — **и на практике это не сработало**: в текущей версии клиента (xpui, веб-ориджин `xpui.app.spotify.com`) этот путь не резолвится, `CosmosAsync` не распознаёт его и пытается сходить через внешний `cors-proxy.spicetify.app`, который блокируется CORS. Расширение логирует это в консоль (`console.error`/`console.debug`) и больше не спамит уведомлениями при каждой фоновой попытке — но дальше просто доверяется встроенному Autoplay Spotify, который для этого и существует и не зависит от недокументированных путей. Если захочешь всё же почистить и свой подбор треков — нужно найти актуальный внутренний путь на этой версии клиента (через DevTools, `always_enable_devtools` уже включён `setup.py`) и заменить `hm://autoplay-enabled`/`hm://radio-apollo` в `fetchStationTracks`.

**Включи Autoplay сам:** Настройки Spotify → Воспроизведение → Autoplay. Без него и без своего подбора очередь может реально закончиться. Расширение один раз подскажет об этом уведомлением при первом запуске волны.

## Настройка

Автоматически (делает всё из шагов ниже сразу):

```
pip install pyinstaller
python scripts/setup.py --github-repo USER/REPO
```

Ставит Spicetify, если его ещё нет, подставляет `USER/REPO` в нужные файлы, копирует расширение в `%LOCALAPPDATA%\spicetify\Extensions`, custom app «Моя волна» в `%LOCALAPPDATA%\spicetify\CustomApps\moya-volna`, включает оба и DevTools, собирает `spicetify_updater.exe`, создаёт задачу в Планировщике (запуск при входе в Windows, без прав администратора). Любой шаг можно пропустить флагом `--skip-install` / `--skip-apply` / `--skip-build` / `--skip-task`. На GitHub коммит/пуш скрипт не делает — это руками.

Вручную, по тем же шагам:

1. Поставь [Spicetify](https://spicetify.app/) и Python 3.
2. Пропиши свой репозиторий вместо `USER/REPO`: в `extension/rivers.js` (`VERSION_MANIFEST_URL`), в `updater/spicetify_updater.py` (`MANIFEST_URL`), в `version.json` (`url`) — и закоммить/запушь.
3. Подключи расширение и страницу:
   ```
   spicetify config extensions rivers.js
   spicetify config custom_apps moya-volna
   spicetify apply
   ```
   (`rivers.js` — в `%LOCALAPPDATA%\spicetify\Extensions`, папка `moya-volna` целиком — в `%LOCALAPPDATA%\spicetify\CustomApps`).
4. Собери апдейтер в exe:
   ```
   pip install pyinstaller
   pyinstaller --onefile --noconsole updater/spicetify_updater.py
   ```
5. Добавь задачу в Планировщик заданий Windows (`taskschd.msc`): триггер «при входе в систему», действие — запуск `dist/spicetify_updater.exe` (из папки, куда PyInstaller положил exe). Апдейтер не требует прав администратора.

## Выпуск новой версии

```
python scripts/release.py 1.0.1
```

Поднимает `CURRENT_VERSION` в `extension/rivers.js`, пересобирает `dist/rivers.js`, пересчитывает SHA-256 и обновляет `version.json`. Дальше — закоммитить и запушить.

## Проверка

- Расширение загружается после `Ctrl+R` в Spotify — смотри консоль DevTools на строку `[rivers] расширение загружено`.
- В левой навигации появился пункт «Моя волна / My Wave» со своей страницей; кнопка-дублёр видна в плеер-баре.
- При коротком плейлисте в конце подгружаются новые треки без остановки воспроизведения — либо через свой подбор, либо через встроенный Autoplay (должен быть включён в Настройках Spotify).
- Повышение версии в `version.json` приводит к обновлению после следующего запуска апдейтера.
- Намеренно испорченный хеш в `version.json` отменяет обновление — видно в логе апдейтера.
- Апдейтер не падает без интернета — ошибка уходит в лог, процесс завершается кодом 1.
